# HackUCD x Stripe 2026 — OutSpoken

Speech coaching for creators to remove disfluencies from their speech

## Live Project

**View the full repository and code:** [jakdevreal/hackucd](https://github.com/jakdevreal/hackucd)

## My Role

- Designed and implemented speech analysis system
- Created OpenRouter/Claude Haiku prompt for AI coaching
- Tested with Claude Sonnet vs Haiku
- Produced marketing video
- Documented feedback format and metrics calculation

## Tech Stack

- ElevenLabs Scribe v2 via OpenRouter (transcription, with word-level timestamps)
- Claude Haiku via OpenRouter (coaching)
- Node.js / JavaScript
- Vue 3 frontend

## Key Features

- Real-time filler word detection
- WPM and pacing analysis
- Actionable, bite-sized feedback
- Tested for accuracy on multiple models
